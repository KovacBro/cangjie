# 会话协议模板（直接粘进上下文）

> 用法：`cangjie block` 的输出替换下面 `【密码本】` 段，其余原样保留。
> 放在系统提示之后、正文之前，且**跨轮次不要改动**（保护 prompt cache）。

---

## 压缩协议

本项目启用仓颉字码压缩。以下 `【密码本】` 中的每个字，代表右侧的完整短语。

**【密码本】**

```
<仓颉v1 pool=auto n=0>
</仓颉>
```

### 使用规则

1. **内部可用**：思考过程、草稿、工具输出、工作记忆包中，可以直接使用密码本里的字，
   例如 `█最大连接数 20` 表示"数据库连接池最大连接数 20"。
2. **对外必还原**：给用户的回答、交付的文件、commit 信息，必须写完整原文，
   **不得出现任何密码本中的字**。
3. **代码不动**：围栏代码块、行内代码、URL、文件路径中的内容保持原样，不压缩、不还原。
4. **不认识的字符**：遇到不在密码本中的符号，按字面理解，不要猜测。
5. **完整性**：引用原文时优先还原，不要用字码代替用户可见文本。

### 上下文结构

```
系统提示 + 密码本（稳定，只追加）
        + 工作记忆包 Z1（每 5–8 轮重建，≤2000 token）
        + 最近 k 轮原始对话
        + 本轮输入
```

### 每轮自检

- [ ] 输出里有没有密码本字符？有就还原
- [ ] 有没有把代码块压缩了？有就重做
- [ ] 密码本版本号变了没？变了要重建工作记忆包
