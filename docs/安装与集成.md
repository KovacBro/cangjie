# 安装与集成（框架无关）

仓颉不绑定任何 Agent 框架。同一个 `SKILL.md` + 同一个零依赖 Python 包，可以：
**当 CLI 用 / 当技能装载 / 当 MCP 工具 / 当库调用**。

---

## 0. 一张表看清该选哪种

| 你的环境 | 接入方式 | 一分钟命令 |
|---|---|---|
| 任何终端 | CLI | `pip install -e .` 或 `python scripts/cj.py …` |
| WorkBuddy | 技能目录 | `cangjie install --target workbuddy` |
| Claude Code | `~/.claude/skills` | `cangjie install --target claude` |
| Codex / Cursor / Cline | `AGENTS.md` | `cangjie install --target agents` |
| Claude Desktop / Zed / 任意 MCP Host | MCP stdio | `cangjie mcp` |
| Python 项目 | `import cangjie` | 见第 6 节 |
| CI | `cangjie doctor` | 见第 7 节 |

---

## 1. 纯 CLI（最通用）

```bash
# 方式 A：不安装，直接跑（把 <repo> 换成本仓库路径）
python <repo>/scripts/cj.py doctor

# 方式 B：可编辑安装，得到 cangjie 命令
cd <repo> && pip install -e .
cangjie doctor

# 方式 C：只要精确计量与造字
pip install -e ".[all]"      # tiktoken + fonttools
```

验证：

```bash
cangjie bench        # 应打印分词器后端与载体单价
cangjie demo         # 内置语料端到端演示
```

> 无网/无 tiktoken 也能用：计量自动退化为启发式（误差约 ±20%），
> 挖掘、编解码、打包全部照常。

## 2. WorkBuddy

```bash
cangjie install --target workbuddy            # → ~/.workbuddy/skills/仓颉
cangjie install --target dir --dest ~/.workbuddy/skills --name cangjie
```

重启会话，技能列表出现「仓颉」。
更新：重跑同一命令加 `--force`。

## 3. Claude Code

```bash
cangjie install --target claude               # → ~/.claude/skills/仓颉
```

Claude Code 会自动发现 `~/.claude/skills/*/SKILL.md`（frontmatter 里的 `name` / `description`
就是它的路由依据）。也可以只装到项目内：

```bash
cangjie install --target dir --dest .claude/skills
```

## 4. Codex / Cursor / Cline / 自研 Agent

这类宿主读 `AGENTS.md`（或等价的项目约定文件）。仓颉会把一段**可幂等更新**的说明写进去：

```bash
cangjie install --target agents                      # 写到 ./AGENTS.md
cangjie install --target agents --dest docs/AGENTS.md # 指定位置
```

写进去的内容带有 `<!-- cangjie:begin … cangjie:end -->` 标记，重复执行会替换而不是追加。
同时把命令入口暴露给 agent：让它自己跑 `cangjie trim` / `cangjie pack` 即可。

## 5. MCP（任何 MCP 客户端）

```bash
cangjie mcp            # 或 python -m cangjie.mcp_server
```

客户端配置：

```json
{
  "mcpServers": {
    "cangjie": {
      "command": "cangjie",
      "args": ["mcp"]
    }
  }
}
```

Windows 上若 `cangjie` 不在 PATH，用绝对路径：

```json
{"mcpServers": {"cangjie": {"command": "python", "args": ["-m", "cangjie.mcp_server"],
 "env": {"PYTHONPATH": "E:/skills/仓颉"}}}}
```

暴露的 7 个工具：

| 工具 | 作用 | 输入 |
|---|---|---|
| `cangjie_trim` | 裁剪冗长输出（省 70–95%） | `text`, `profile`, `max_lines` |
| `cangjie_sift` | 上下文安检（有用/没用，报告或筛除，1.0.1 新增） | `text`, `drop`, `root` |
| `cangjie_pack` | 生成定长工作记忆包 | `root`, `budget` |
| `cangjie_compress` | 字码压缩（无损） | `text`, `root` |
| `cangjie_expand` | 还原（对外输出前必调） | `text`, `root` |
| `cangjie_block` | 输出密码本块 | `root` |
| `cangjie_stats` | 字典/命中/ROI | `root` |

协议版本 `2024-11-05`，JSON-RPC 2.0 + 换行分帧，零第三方依赖。
自测：`python tests/test_cangjie.py -k Mcp`。

## 6. 当 Python 库

```python
from cangjie.codec import Codec
from cangjie.state import Dictionary
from cangjie.trim import trim
from cangjie.memory import State, Roll, build_pack

dic = Dictionary.load(".")                 # 读 .cangjie/dict.json
codec = Codec(dic.pairs(), protect_code=True)

enc, stats = codec.encode("向量检索之后再重排序")
assert codec.decode(enc) == "向量检索之后再重排序"   # 无损

out, st = trim(long_log, profile="pytest", max_lines=60)   # 有损裁剪

State.load(".").add("decided", "改用 fp16")               # 状态卡
pack, detail = build_pack(".", budget=2000)               # 定长包
print(detail)                                             # 各段 token 明细
```

## 7. CI

```yaml
- name: cangjie doctor
  run: |
    python -m pip install -e .
    cangjie doctor            # 可逆性 + 字典完整性，失败退出码非 0
    python tests/test_cangjie.py
```

`doctor` 的检查项：分词后端、载体池、字典条数、4 组样本的可逆性、载体字是否单字符/是否重复。

## 8. 团队协作

- `.cangjie/dict.json` **建议进 git**：团队共享同一份术语表，压缩结果可复现。
- `.cangjie/state.json` / `roll.jsonl` 是本地的，**不建议**提交（每人任务不同）。
- `.cangjie/ledger.jsonl` 可提交（用于统计节省量），也可忽略。

`scripts/` 下加一个 `post-merge` 钩子跑 `cangjie doctor` 可防字典被改坏。

## 9. 卸载

```bash
rm -rf ~/.workbuddy/skills/仓颉      # 或 ~/.claude/skills/仓颉
pip uninstall cangjie-skill
rm -rf .cangjie                      # 工程内状态（可选，删了不影响原文件）
```

`install --target agents` 的清理：删掉 `AGENTS.md` 里
`<!-- cangjie:begin … cangjie:end -->` 之间的内容即可。
